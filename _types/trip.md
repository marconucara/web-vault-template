# Trip

A destination, from the first idea to the trip itself. Use `status` to track
where it stands:

- **Idea** — a rough prompt, barely scoped.
- **Scoping** — actively gathering information: areas, tours, dates.
- **Planned** — dates and itinerary settled.
- **Done** — travelled; kept as a record.

A Trip note is a good place for a day-by-day itinerary with a Google Maps link
per stop: each link becomes a place card, and the whole trip shows up as pins on
one map.

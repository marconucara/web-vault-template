# Note

A general-purpose document — research, meeting notes, a draft, or anything that
does not fit a more specific type. When in doubt, it's a Note.

Give a note its type with a `type:` line in its frontmatter:

```yaml
---
type: Note
---
```

Notes of a given type are grouped together in the sidebar. A type only appears
there once at least one note uses it.
